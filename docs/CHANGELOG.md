# 项目变更记录

当前开发范围见[README](../README.md)和[三模块总体设计](modular-context-provider.md)。以下记录阶段演变，旧日期的目标和实施顺序不作为当前要求。

2026-09-15 实施[资源语义目录](resource-semantics.md)，继续沿用 MOD 0.6.0 和 API／SDK 1.1.0：从安装游戏按配置优先级选择完整 TGI，保存被覆盖候选与冲突；扩充 13 类资源及独立名称／描述／tooltip。运行时返回可选详情，离线 v2 重解释不改历史事实；修复空代词槽及可核实模板，补日期和 SIM_LIST 子项证据。实测数据、内存和检查范围见[验证](validation/2026-09-15-resource-semantics.md)。

2026-09-15 新增[附近实体查询](nearby-entities.md)，MOD 保持 0.6.0，API／SDK 升为兼容的 1.1.0。支持 Sim／物件筛选、水平或三维半径、楼层和房间约束、稳定排序、数量限制和未知状态；排除库存内容，不产生连续位置历史。增加 SDK 示例与 `co.nearby` 导出入口，详细离线／构建证据见[验证](validation/2026-09-15-nearby-entities.md)。

2026-09-15 首局后的 0.6.0 修正：不再保存 TimeSince 计时统计；已确认的进食／游戏垫内部步骤改为内部层；修广播器类型、配方／情绪／来源交互名称与空文本兜底；按效果角色组织中文；补制作、付款与库存同步调用来源，保存入口健康和回调诊断。138 项离线测试通过，58 个声明的游戏方法符号核验成功。旧日志的策略重放可排除 2676 个计时事件、重分层 343 个内部交互；这是离线对照，不是新实机结果。见[修正验证](validation/2026-09-15-event-quality-fixes.md)。

2026-09-15 完成本轮事件扩展实现与 0.6.0 试用包，详见[当前覆盖](event-coverage-0.6.0.md)和[验证报告](validation/2026-09-15-event-expansion.md)。新增生活事件、具体社交动作、多实体角色、直接数值效果、动作／效果分组、历史身份查询及 200,000 条 FIFO；保留内存和磁盘独立保护。没有持续数值采样、活动容器或家庭账本；本轮未安装、启动游戏或执行 Git 发布。

首次扩展实现阶段共 126 项离线测试通过，49 个声明的游戏方法符号核验成功；21 万条重型样本在临时测试预算下保留 20 万并淘汰最早 1 万，正式内存预算保持 1536 MiB。另修复 Windows PowerShell 5.1 安装器默认包目录的求值时机，默认路径测试和 WhatIf 预检通过。
