## 2. 保留的扩展方向

- 长期记忆、印象与遗忘：以已记录事实为依据，明确派生来源和可回查范围。
- 角色知识：区分事件时间和知情时间，不能仅因同场或距离近就认定目睹。
- 指定历史时点状态重建：需要被选字段的有效基线、实际变化、连续性与重放验证。
- Overlay 消费与返回：区分生成、提交显示和已确认显示，处理请求关联与过期结果。
- LLM 事件执行：提案、执行前复核、实际执行和结果回录分开设计，不把文本当成游戏已发生事实。
