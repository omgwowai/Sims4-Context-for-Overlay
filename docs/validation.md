## 待验证与已知缺口

- Autonomy 立即执行、单独目标选择层、缓存与并行交互复杂组合、完整会话诊断及受控性能对比。来源为 Autonomy 的交互数量不是独立已提交决策数量。
- 职业、人生节点、Sentiment、库存拆堆与隐藏移动等缺少足够实机样本；Loot 和广播覆盖受已加载具体实现限制。
- 主层仍可能包含技术条目，未知 Buff／交互保留未解释标记；隐藏聊天名称仍有参数类型缺口，尚无 UI 队列名称兜底成功的实机证据。
- 复杂代词、姓名前缀、SIM_LIST、年龄条件、部分日期格式和小数金额等明确未解析。基础情绪说明及 tooltip 不代表客户端条件已判断。
- 附近实体接口的空间边界、真实消费 MOD 的加载／旅行／线程时序，以及新增日期格式与长详情窗口仍需针对性实测。
- 200,000 是事件数量上限；较重事件可能先触发 1536 MiB 记录预算。序列化计时不包含 GSI 生成成本，历史截图或旧版本测试不能替代新性能测量。

复测方法、命令和测试脚本见[开发与调试](development.md)。一次查询的 `complete` 不表示全部历史存在、所有文本已解析或所有队列数据已经耐久落盘。
