# 未来方向

这里记录尚未完成的工作，不作为当前 API 契约。当前已经可用的能力以[文档入口](index.md)、[API 参考](public-api-v2.md)和[分层事件查询](event-views.md)为准。

## 后续优先级

1. **真实下游 MOD 联调**：覆盖游戏回调调度、后台模型结果回写、session 变化和长时间运行，确认 SDK 的线程与生命周期边界在第三方 MOD 中容易实现。
2. **扩大实机覆盖**：补充旅行、读档、职业、人生节点、Sentiment、库存、隐藏移动和更多 Autonomy / 并行交互样本；保持未观测内容明确标记。
3. **分层视图增量协议**：定义源事件修订如何替换或移除既有 organized / recap 条目，以及时间窗口查询的稳定语义；在协议确定前不要把 read_event_changes 当作 recap 增量。
4. **文本与资源覆盖**：继续审阅官方资源、分类和参数缺口。已见实例包括 Nova 的布朗尼制作阶段分类缺口，以及 Eddie 小睡时大量内部数值通知的阅读去向；保留原始名称、解析状态和证据，不用猜测填满未知文本。
5. **负载与预算边界**：用更多真实日志测量查询、导出、取消和回收行为，区分受控估算预算与游戏进程实际工作集，不把单个样本推广为通用性能保证。

每项工作都应补对应测试或可复现验收步骤；已完成的计划不另存为待办文档，结果直接更新到当前契约、验证摘要或 Git 历史中。
