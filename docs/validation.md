# 验证摘要

当前文档对应 **ContextOverlay 0.14.1 Preview / API、SDK 2.6.0 / schema 2**，核验日期为 **2026-10-08**。开发与实测环境为 Windows、游戏 `1.126.73.1030`、简体中文。以下明确区分实机采集、源码回放和编译包回放；旧版本的通过记录不视为当前版本重新实测。

采集、自动整理和持久化已有实机核对，气泡事件窗口已通过源码及最终编译包的离线一致性验证。**最新一局没有点击“查看状态与历史”**，因此没有补充当前版菜单出现、窗口显示或下游 MOD 实时调用的验收。

## 0.14.1 发布检查

发布前修复了旧 Context 离线翻译问题：0.12.0 导出的 `value.recent` 被误按 `value.events` 读取，产生 `KeyError`。修复后真实旧导出可重新生成说明，按“旧版气泡缓存快照”展示，原字段和截断语义不变；新 API 继续使用事件窗口。Markdown／JSON、空缓存、截断缓存及新窗口提示均有回归覆盖。

CPython 3.7 **441 项离线回归通过**（30.110 秒），77 个游戏原生 hook 符号全部解析。在最近日志中，以四位人物各自最后发送时点为准，向前查询 60 个游戏分钟，分别命中 **6／5／4／2** 条。Context、历史分页与落盘 Events 的身份、顺序、payload、cause 一致，Context 不遗留游标；只从离线索引移除匹配事件后，Context 标记缺口，落盘查询仍能取回。最终编译包重复通过相同回放，所有 `context_overlay` 模块来自 `.ts4script`，没有回退源码。原日志哈希未改变。

源码／构建 manifest、字节码、Windows／SDK ZIP 内容及本地安装哈希核对通过。游戏脚本 SHA-256：

```text
ff20b4e07c5a4bef835488c24bf199a9e259e7eedbe9e46867d4daf36b8c88a7
```

发布时本地安装与发行包使用相同脚本，0.14.1 修复未另启游戏验证。版本与下载见 [v0.14.1 Release](https://github.com/omgwowai/Sims4-Context-for-Overlay/releases/tag/v0.14.1)；逐轮安装备份、修复依据和旧样本保留在[历次验收明细](validation-history.md)。

## 性能与大日志参考

以下都是指定版本、指定来源的历史测量，不是当前版本或游戏帧率的保证。对照使用同一冻结来源、独立 Python 3.7 进程；不同轮次的机器负载不同。

| 历史对照 | 直接导出耗时 | 峰值工作集 | 结论 |
| --- | --- | --- | --- |
| 0.10.6 → 0.10.7 | 16.6 → 44.8 秒 | 463.1 → 256.5 MiB | 按需解码降低峰值，增加耗时 |
| 0.10.7 → 0.10.8 | 35.5 → 10.7 秒 | 257.6 → 442.6 MiB | 预算允许时共用解码结果，以内存换时间 |

0.10.9 编译包曾在默认预算下离线恢复约 190 MiB、60 小时的旧采集；0.10.10 编译包在四人物长会话中通过 578 页完整编码预算检查。这些是离线样本，不能写成旧版游戏自动导出或当前下游调用已经验收。完整来源哈希、截点和测量条件见[历史性能记录](validation-history.md#性能与大日志参考)，当前预算见[来源与预算](event-views.md#来源与预算)。

## 尚未证明的内容

- 当前版本的完整 Inspector 点击和气泡栏目实机流程、真实下游 MOD 调用与后台结果回写。
- 气泡旅行后的持续采集、困扰／婴儿感受和更多第三方发送路径；一般事件的更多职业、人生节点和复杂库存样本。
- 视锥边缘精度、持续移动跟随、旅行同步和特殊镜头；单次抽测不等于渲染器精确可见性。
- 第三方 MOD 覆盖兼容、全部资源名称与参数解析、整体事件召回率或语义准确率。对账通过只证明来源有去向。
- 人物的知情、动机、目睹或记忆，以及任意历史时刻的完整状态。发送事件和离散观察不是连续录像。
- 固定压缩比例、token 数或性能上限，输出取决于规则、数据、编码器及机器负载。
