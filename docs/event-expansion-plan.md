# 0.6.0 事件采集完善：访谈决定与实施约定

日期：2026-09-15。状态：访谈结束，本轮已实现并完成源码／离线验证，形成 0.6.0 试用包；实机证据待补。当前完成范围见[覆盖说明](event-coverage-0.6.0.md)。本文件保留十项设计决定及实施约定；后续新增决定是数量满时 FIFO 淘汰旧事件，不再因数量上限暂停。

0.6.0 是整轮事件完善的版本号，后续改动继续沿用，不为每个小步骤递增。先完成源码核验与离线检查，交付可试用版本；各类实机证据在后续实际使用中逐步补齐。试用交付不等于全部领域已通过游戏验证。

## 1. 已确认的决定

| 项目 | 本轮决定 | 直接影响 |
| --- | --- | --- |
| 定版范围 | 常见生活事件：日常行为与结果，并包含技能、特征、关系、职业和人生节点；资料片专项以后扩展 | 不要求把覆盖调研中的全部领域一次实现 |
| 数值历史 | 只记录有明确效果来源、真实前后值的直接效果 | 不保存吃饭／睡觉等持续活动的开始／结束数值，也不记录其期间差；当前值通过 Context 获取 |
| 社交动作粒度 | 讲笑话、夸奖、侮辱等具体动作各一条主要事件 | 有依据时关联所属聊天；动画和姿态调整继续在内部层，不因 mixer 身份统一隐藏 |
| 本地事件的实体边界 | 根据事件发生时的本地证据保留身份、角色和可核实终态 | 新生儿、死亡 Sim、进入库存的物品等可以被历史引用，不要求处理回调时仍有可见本地实例；不持续采集其场外状态 |
| 动作与效果展示 | 默认动作一条，效果进入详情；效果仍是可独立查询的事实 | 只凭明确关联归入动作；无法归因的状态变化独立显示 |
| 隐藏／未知条目 | 已选领域中的离散变化全部采集，按用途分层；未知先保留可见 | 确认是技术机制的进调试层；未识别条目显示原始信息并标为待解释，不能因无中文名而隐藏 |
| 感知／反应 | 接入游戏实际触发的反应、广播效果实际作用及可核实来源 | 不凭距离推断目睹，不推断角色理解；同场存在、受到效果作用和反应触发分别表达 |
| 活动／Situation | 本轮不接入独立活动及其参与关系 | 不建立活动容器，不采活动加入／退出、角色、目标或成绩；其中具体行为照常记录 |
| 日常收支 | 在工作结算、购买、制作、付款等具体事件中记录可核实金额与来源 | 暂不建立独立家庭资金流水；不从配置费用直接推断真实扣款 |
| 验收门槛 | 先源码核验、离线检查，再交付可试用版本 | 实机验证状态逐领域明确列出，由后续实际使用补充证据；不以每类都有实机案例作为本次试用门槛 |

前述选择中的“只记录能确定的直接效果”约束的是数值效果，不禁止保留其他已确认发生、但来源未知的离散事实。例如原生 Buff 添加可以独立记录，不能在缺乏来源证据时写成某次交互造成。

## 2. 本轮范围的具体展开

本表把“常见生活事件”对应到已调研的入口，属于实施分组；每个字段和发送路径仍需在接入时登记实际支持情况。资料片缺失、源码入口不可用或只有局部支持都需要显式报告，不能据领域标题承诺全玩法覆盖。

| 分组 | 本轮目标 | 明确的限制 |
| --- | --- | --- |
| 行为与结果 | 具体社交动作、参与角色、交互阶段、退出类型、可核实 outcome，以及有证据的续接／效果关联 | 自然退出、选择成功分支、后续效果执行成功分开表达；不收自主候选评分 |
| 状态效果 | Buff 增减与可获得的原因／来源／刷新信息、情绪切换、常用物件状态、具有明确来源的实际数值效果 | 不全局接入连续数值变化流；不做交互边界数值快照；不把目标差当实际净差 |
| 制作与物品 | 制作及最终产物、制作者、品质等结果；库存转移的物件、数量、来源／去向和确认结果 | 关注有本地发生证据的操作；区分堆叠、隐藏库存、加载、转移、替换和真正销毁 |
| 人物发展 | 技能等级、特征获得／失去，以及相关的解锁／成长节点 | 记录离散节点；初始化、读档恢复、回溯补授不当作当下新获得 |
| 社交关系 | 关系标记、配偶变化、知识获得／失去、Sentiment 的获得／替换／移除等离散事实 | 双方引用按本地事件证据建立；不持续跟踪场外角色；不记录关系或 Sentiment 强度曲线 |
| 职业与人生 | 通用职业变动和工作结算；年龄、家庭关系、怀孕／分娩／收养／死亡等已调研的常见节点 | 不借此采集场外工作过程；特定资料片职业、教育或专属玩法不自动纳入 |
| 反应与受影响 | 游戏反应、广播效果实际作用、发起源与受影响实体 | 回调发生不自动证明效果成功；持续影响的重复通知与新的实际效果必须区分，不能固定按时间窗吞掉真实发生 |
| 事件金额 | 工作收入、购买／制作／付款等事件中已确认的实际金额 | 不建设独立家庭账本，不宣称涵盖全部资金收支 |

未选择的领域保持待扩展：独立 Situation／活动生命周期和参与关系、健康／超自然专项、经营及其他资料片专项、独立环境事件体系、家庭资金流水。既有行为或状态可能留下这些玩法的旁证，不能据此宣称对应领域已完整接入。

## 3. 数据与展示约定

### 3.1 共享事实与实体索引

沿用“统一事件表 + 每实体关联事件 ID 容器”。执行者、接收者、其他参与者、产物及受影响对象引用同一事实，并记录有来源依据的角色；不为每个接收者复制一个独立发生。

动作与效果分别保留事实身份，再以可核实证据建立关联。默认窗口将已关联效果放入动作详情，动作摘要可以概括已确认结果；底层事实仍可独立查询。一个动作产生多项效果、同一个效果被多个通知报告、效果先到动作后到等情况，都不能靠相近时间和相同名称强行合并。

具体社交动作默认是主要事件。是否属于技术机制应有分类依据，不能只看 `is_super`、资源有无中文名称或单一的 `visible` 标记。未知用途的离散条目默认可见，保留原始名称／ID 和待解释标志。

### 3.2 本地发生与历史引用

新增采集仍以本地发生证据为界。回调处理时实体可能已死亡、离开实例集合或转入库存；保留事件中的身份与角色以及能够确认的终态，不查询或持续追踪其场外当前状态。

当前实现已拆开 Context 实时读取与历史身份解析：已离开实体可以使用本运行保留的身份按已知 ID 查询；当前状态缺失继续显式报告，不伪造快照。FIFO 清除最后一个引用且实体不在观测范围后，其历史身份可以释放。

### 3.3 数值与原因

数值事实必须同时具备明确效果来源、真实 before、真实 after。操作配置的 amount、clamp 前 delta、活动期间观测差都不能替代真实净变化。没有满足条件的入口时，不生成该数值效果，能力状态中说明缺口。

吃饭、睡觉等持续活动可以有行为、Buff、物件状态或其他离散结果，但本轮不保存其开始／结束数值。Context 按请求读取当前值，记录器没有数值定时采样或恢复开关。

### 3.4 下游兼容与覆盖说明

这是实现约定，不新增访谈范围：沿用现有公共 API／SDK 入口、独立 JSON 返回、游戏线程约束、会话检查和固定版本分页。不能因窗口折叠而删除底层效果事实或改变既有字段的含义。

新增分类、cause、roles、group_effects、历史身份和能力发现已同步到实现、公共 API、SDK 示例与窗口。history.py 支持 interaction／state_change／game_event；已有接口默认返回独立事实，新增分组为显式选项。字段与实际入口以[覆盖说明](event-coverage-0.6.0.md)为准。

## 4. 实施顺序

1. **整理事实身份与查询基础。** 明确事件类别、参与角色、动作与效果关系、本地范围证据、历史身份引用和逐领域能力状态；保留现有索引与分页语义。
2. **修正已有行为和展示。** 将具体社交动作纳入主要事件，补多参与者、结果和确定的关联；实现动作摘要与效果详情，未知用途默认可见。
3. **补日常结果。** 接入严格来源约束下的数值效果、Buff／情绪、制作产物、物品转移、反应／广播作用，以及事件金额。
4. **补常见生活节点。** 分组接入技能、特征、关系、职业、成长与家庭节点；逐一处理初始化、重复通知和终态实体问题。
5. **交付试用。** 更新能力矩阵、接口说明、示例、变更记录和安装产物；完成适配器与整条查询／展示链的离线验证，明确尚未获得实机证据的部分。

## 5. 检查与交付

离线检查需要验证行为，而非只验证新增函数能运行：

- 同一交互多次通知、双向关系、多个参与者投递保持正确身份；连续两次同名动作不会误合并。
- 自然退出、取消、失败分支、无效果和实际效果分别表达；无来源或无真实前后值时不生成数值事实。
- 没有恢复连续采样，也没有新增吃饭／睡觉等活动的边界数值记录。
- 本地事件引用已离开实体时，历史仍能按 ID 查询；当前 Context 的范围检查继续有效。
- 效果可独立过滤查询，窗口折叠后可展开；主要社交动作、内部机制和未知条目的显示符合约定。
- 技能／特征／人生等来源区分真实新发生、初始化、恢复和补授；只有新数值或通用刷新通知时不补造旧值、原因或具体目标。
- 新类别经过历史索引、稳定分页、中文／原始表示及 SDK 返回链；旧查询入口与错误语义保持兼容。
- 扩展后重新检查事件量和关联开销；数量满采用 FIFO 并公开淘汰数；内存、写盘与采集失败仍显式暂停，不宣称无限或完整历史。

每个领域分别记录源码核验、离线检查和实机证据。本轮实现未安装、未启动游戏，未发布附件，也未 commit、push 或 merge。已安装及内部附件仍为 0.3.2。

## 6. 沿用的边界

当前地块为主要观测范围，不持续采集场外角色；每次运行／读档隔离历史，不自动跨运行串联。当前数值通过 Context 读取，不恢复连续数值采样。默认事件容量仍为 200,000，满时按首次接收顺序 FIFO 淘汰；既有内存、写入队列、运行输出和磁盘预算仍独立生效，错误显式暴露。触发来源不扩写为心理动机，未知字段不猜测。
