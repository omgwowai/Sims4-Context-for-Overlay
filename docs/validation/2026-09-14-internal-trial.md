## 安装与调用检查

CPython 3.7.9 下共 **76 项离线检查通过**：此前核心／窗口的 66 项，加上 8 项 Windows 安装检查和 2 项消费 MOD 示例检查。记录在本地 `.validation/internal-trial-tests.txt`。

Windows PowerShell 5.1 安装检查使用临时目录，覆盖首次安装、相同包重复安装、升级备份与原子替换、损坏包、错误字节码、包内版本不一致、重复安装包、预览不落盘和游戏运行时拒绝安装。多项行为可在同一测试中覆盖。原始存档替身、其他 MOD、配置和选项均保持原字节。

测试中替换进程发现结果，分别模拟游戏已关闭和仍在运行，不依赖真实桌面状态；分发脚本仍执行实际游戏进程检查。首次测试发现 PowerShell 5.1 对 `File.Replace` 的 null 字符串转换与 `-WhatIf` 传播问题，已修正并通过完整检查。

消费示例使用真实 Collector／Recorder，替换 EA 读取和日志写盘，核对可序列化 Context、实体历史分页、查询释放和跨运行失效。它是绑定 0.3.2 的接入示例，不是任意第三方 MOD 的游戏兼容验收。
