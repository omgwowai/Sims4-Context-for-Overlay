## 行为与接口检查

CPython 3.7.9 下 **126 项离线测试通过**。保持原测试并补充了：

- FIFO 按首次接收淘汰，修订／游戏时间不改变顺序；淘汰清理实体和时间索引，失败提交不淘汰；JSONL 重放执行淘汰。
- 分组保留独立效果事实，过滤或淘汰动作后效果独立显示；快照冻结效果与修订，预算与释放计数正确。
- 数值只在明确操作内记录真实限幅前后变化；无来源、旧值缺失、无变化、加载或操作异常不生成，采集不调用 get_value。
- 技能记录实际离散等级，忽略初始化／无等级变化，保留降级；Buff handle 刷新及嵌套移除去重。
- 配偶双向通知去重、离婚和再婚；知识与 Sentiment 实际变化、替换与方向。
- 本地死亡后身份查询、出生子女及制作产物角色；怀孕、降职和退休的真实状态变化。
- 库存失败／无变化／加载不产生虚假事件，实际插入、隐藏、拆堆和移除保留状态；支付保留真实金额，失败和无归因全局资金变动不记录。
- 广播通过外层条件后才记录，持续回调更新同一事实，每次计数、移除、再次施加保持正确；不推断效果成功。
- 嵌套解锁不同里程碑各自保留，恢复上下文不当新人生事实。
- SDK 透传新参数，已离开实体的历史查询不调用实时解析；窗口的分组详情和生活事件过滤。
- 原有当前 Context、语义解析、分页、线程／会话、安装器和写入故障检查继续通过；后台范围检查不读取或记录连续数值。
- 修复 Windows PowerShell 5.1 默认安装路径在参数初始化时为空的问题；模拟解压包的默认目录测试及真实用户目录的 WhatIf 预检通过，未执行安装。

入口由模拟对象执行真实适配代码检验，不能代表游戏中全部生命周期已验证。尤其资料片分支、延迟加载子类、其他 MOD 的 Hook 共存和游戏帧耗时需要实机证据。

## 容量与 FIFO 压力测试

新增 [benchmark_fifo.py](../../scripts/benchmark_fifo.py) 使用旧实机日志中的 571 个交互结构，加上本版适配器形式的合成生活事件。每个合成事件关联一个新物件 ID，刻意检查大量身份创建和淘汰；结果不代表普通存档的平均负载。

| 测试 | 结果 |
| --- | --- |
| 默认 1536 MiB，重型样本 | 保留 133515 条时，下一个事件触发 history_memory；旧事件保留，明确暂停 |
| 默认 1536 MiB，较小样本 | 保留 167841 条后触发内存保护，未达到数量上限 |
| 重型样本，测试预算临时改为 3072 MiB | 210000 条全部接收，保留 200000，FIFO 淘汰最早 10000 |
| 200000 条时正文／索引计量 | 2412864776 字节，约 2.25 GiB |
| 再写 10000 条后的计量 | 2412948368 字节；与满容量时接近，没有随累计条数线性增长 |
| 21 万条后测试进程私有内存 | 2776141824 字节，约 2.59 GiB，包含大量单独实体索引／身份 |
| 完整构建与 1 万条淘汰 | 约 36.6 秒，离线批量，不是游戏帧延迟 |
| 一致性断言 | 当前数量、淘汰数量、旧事件消失、固定快照存活、旧身份清理、引用总数、索引一致、快照释放，全部通过 |

正式默认内存预算**没有调高**。200000 是数量上限，较重的事件可能先触及独立内存保护，不能依据旧版 20 万条测试承诺新版任意构成都能存满。内存计量不是整个游戏进程硬上限；快照、Hook 缓存、游戏和其他 MOD 还会使用内存。

压力测试使用只计序号和序列化字节的写入替身；没有真的写入 21 万条日志，也没有测量 fsync。原有写盘故障测试验证提交失败不会淘汰。追加证据日志仍受单次运行 2 GiB 上限，FIFO 不压缩旧磁盘文件；累计修订与广播回调会继续占磁盘。

21 万条重型样本序列化计量为 419149163 字节，约 400 MiB；不包含真实游戏中额外的反复修订和其他导出文件。

## 构建与交付

用匹配游戏字节码的 Python 3.7 构建 `dist/ContextOverlay.ts4script`，带本机中文词表。Windows 试用 ZIP 含安装器、校验清单、公共 API／SDK、事件示例、覆盖和验证文档。SDK 源码包不含 EA 游戏数据。

构建清单、源码摘要、逐方法符号核验、两次默认预算保护结果和完整 FIFO 数据保存在[机器可读报告](2026-09-15-event-expansion.json)。ZIP 自身摘要以旁边 `.zip.sha256` 为准，避免报告与包含报告的 ZIP 相互引用。

本轮没有改动游戏安装包、配置或存档，没有上传附件。试用时退出游戏，解压 Windows ZIP，再运行 `Install.cmd`。旧 config.json 若有 `record_need_changes`／`sample_interval_sim_minutes`，须先移除这两个已删除的采样字段，详见[安装说明](../install.md)。
