# 需求历史与近期事件展示改进（0.3.1）

日期：2026-09-14。分支：`zixuan/first-runtime-implementation`。

用户亲自试验后确认 0.3.0 窗口可以打开，并指出两项问题：需求采样变化占据最近 5 条事件；事件列表的空物件缩略图显示红色 X。运行日志也记录了该版本的 INSPECTOR READY 和 Sim／物件的 INSPECTOR OPEN。此反馈只证明已实际使用这些入口，不扩大为完整场景验收通过。

## 修改

- 新配置 `record_need_changes` 默认 false。EAAdapter 的后台连续采样不再读取、提交 `needs.*`，不生成需求差异历史；当前 Context 的 `read_needs()` 不受影响。显式设为 true 并重启可恢复记录。
- 关系数值采样与 Buff、关系标记、物件状态、交互等其他记录继续工作。需求数据不可用时也不阻断独立的关系采样。旧运行日志不修改。
- 首页使用 `UiDialogOkCancel` 文字对话框，近期最多 5 条主要事件在正文按“时间｜事件说明”逐行显示。每条摘要最多 120 字符，长内容用省略号提示，完整内容从历史页面查看。
- 首页不再创建事件 `ObjectPickerRow`，没有空物件缩略图槽位；“当前状态”“历史事件”“刷新”和“关闭”使用文字响应按钮。详细状态与完整历史继续使用已有列表选择器，本次没有改写整个 UI 系统。

## 检查与安装

CPython 3.7.9 下 **66 项离线测试通过**。新增检查覆盖默认关闭需求采样但保留关系变化与当前需求、显式开启需求采样，以及文字首页无物件行、响应按钮无需先选行、关闭与取消正确分发。原有目标固定、分页和生命周期等检查继续通过。
