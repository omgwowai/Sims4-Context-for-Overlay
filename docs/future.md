# 未来方向

这里记录尚未完成的工作，不作为当前 API 契约。当前已经可用的能力以[文档入口](index.md)、[API 参考](public-api-v2.md)和[分层事件查询](event-views.md)为准。

## 后续优先级

1. **真实下游 MOD 联调**：覆盖游戏回调调度、后台模型结果回写、session 变化和长时间运行，确认 SDK 的线程与生命周期边界在第三方 MOD 中容易实现。
2. **补齐界面与实机覆盖**：验证人行道聊天中的 Inspector 入口、窗口翻页及气泡栏目；最新 0.14.0 一局未点击窗口。继续补充气泡跨区域旅行、困扰／婴儿感受、职业、人生节点、库存、隐藏移动和更多 Autonomy／并行交互样本。
3. **派生视图的时间窗口与增量协议**：Events 已支持时间筛选；organized／recap 仍需定义跨窗口活动和依赖的处理方式，以及修订导致的替换／删除语义。协议确定前不要把 `read_event_changes` 当作 recap 增量。
4. **文本与活动规则覆盖**：继续审阅官方资源、分类和参数缺口。最新会话有 18 条家庭成员气泡来源已知但尚未可靠归入活动，涉及情绪闲置、动画、社交及职业／学校等。保留来源并按精确证据补规则；历史案例中的制作阶段、内部数值通知和名称缺口同样保留，不用猜测补全。
5. **负载与预算边界**：用更多真实日志测量查询、导出、取消和回收行为，区分受控估算预算与游戏进程实际工作集，不把单个样本推广为通用性能保证。

每项工作都应补对应测试或可复现验收步骤；已完成的计划不另存为待办文档，结果直接更新到当前契约、验证摘要或 Git 历史中。
