# 验证摘要

当前源码为 **ContextOverlay 0.11.0 / API、SDK 2.3.0 / schema 2**。各项证据保留实际采集和回放版本；旧版本的通过记录不视为当前版本重新实测。环境为 Windows、游戏 `1.126.73.1030`、简体中文。下面区分真实游戏采集、源码回放和编译包回放；单次样本通过不代表所有玩法或第三方 MOD 都已覆盖。

## 最近一局：Nova（2026-09-22）

采集版本 **0.10.10**，session `fe8617d8564e4a9b864201db6dbf7344`。`validate_run.py --require-closed` 通过：接收、落盘、session_end 和导出截点均为 **3,796**，无积压或清理错误；最终来源 **23,607,574 字节**。manifest、导出状态与 latest 一致，9 个内容文件哈希和人物对账通过，游戏自动导出耗时 **1.391 秒**。

当前源码查询核心对同一来源完成四层全量分页，organized 和 recap 与游戏自动导出逐项一致，并核对烹饪、电脑游戏活动的单元、事件及修订解释。此检查未重新启动游戏或接入下游 MOD。

人物的 **3,653 records / 1,454 events / 890 organized / 70 recap**、分类和证据链集中见 [Nova 实例](event-layers-example.md)，其中保存完整来源哈希和快照身份。

## 性能与大日志参考

以下比较均使用**同一冻结来源、独立 Windows Python 3.7 进程**；各轮机器负载不同，不把不同轮次拼成同一条性能曲线，也不作为游戏帧率承诺。

| 对照 | 直接导出耗时 | 进程峰值工作集 | 结论 |
| --- | --- | --- | --- |
| 0.10.6 → 0.10.7 | 16.6 → 44.8 秒 | 463.1 → 256.5 MiB | 按需解码减少峰值，增加解码耗时 |
| 0.10.7 → 0.10.8 | 35.5 → 10.7 秒 | 257.6 → 442.6 MiB | 预算允许时复用解码结果，以内存换取速度 |

两轮均使用 9,619 个最新事件的固定前缀，SHA-256 `7141d0784687355bd1dcc283177ecd5c74022eb94f758fce6e6942cdc5919329`；输出事件、活动和审计保持一致。4 GiB 是每个查询 store／导出任务的估算预算，不是上表进程峰值或游戏总内存上限，当前限制见[来源与预算](event-views.md#来源与预算)。

另有 session `ec6cf833bb44453db0fae4d41b355486` 的约 60 小时旧采集：暂停时 **199,457,340 字节、36,347 条记录、16,650 个最新事件**。旧版因 128 MiB 来源上限拒绝导出；0.10.9 编译包默认 worker 回放 **42.125 秒**成功，峰值工作集约 **746 MiB**，27 文件校验通过。最终关闭来源为 **199,622,687 字节、36,492 条记录**，新版离线恢复耗时 **40.656 秒**；最终 SHA-256 为 `fd291e17b7c97dcba53af7ee9e148d9327385eeb781a9b1e7d7cd4325c4eee1c`。原游戏的失败导出状态没有被改写。

## 尚未证明的内容

- 视锥的渲染器精度、持续移动跟随、旅行后实机同步及特殊镜头；离线边界测试不替代这些样本。
- 真实下游 MOD 的加载顺序、回调调度、后台模型回写与长期运行；完整旅行后的持续采集，以及更多职业、人生节点、Sentiment 和复杂库存样本。
- 第三方 MOD 覆盖兼容、全部资源名称／语法解析、总体经历召回率或语义准确率。对账通过只证明来源有去向。
- 人物实际知情、动机、目睹或记忆。离散游戏画面不是连续录像；精确执行边界来自日志。
- 固定压缩比例或 token 保证。历史 recap 样例曾实测约 8–10 千 token，取决于规则、数据与编码器，不是截断目标。
